***ระบบจัดการตารางทำงานของพนักงานแบบใช่งานร่วมกันหลายแผนก***
1.มีการจัดการ Role User สำหรับจัดการระบบภายในแบ่งเป็น Admin และ User
2. database ข้อมูลพนักงานที่เชื่อมโยงกันด้วยหมายเลข GID และหรือ Employee No. โดยสามารถอับโหลดด้วย Template ครั้งละหลายรายการหรือรายบุคคลกำหนดได้ว่าพนักงานคนี้ทำงานแบบเข้ากะหรือไม่ (Shift)สามสรถอับเดทแก้ไข Activate หรือ Deactivate ได้ด้วย Admin
3.มีการอับโหลดตารางพนักงานรายเดือนแบบแยกแผนกซึ่งภายในเดือนอาจมีการอับโหลดทับหลายครั้งเนื่องจากมีการอับเดทข้อมูลหรือสามารถแก้ไขผ่านหน้าโปรแกรมได้ ในการอับโหลดจะบังคับเลือกข้อมูลเดือน-ปี และแผนกก่อนทุกครั้งพร้อมทั้งตรวจสอบรายชื่อพนักงานว่าถูกอับโหลดถูกแผนกหรือไม่ก่อนการอับโหลด
4.มีระบบอับโหลด Shift Code ของแต่ละแผนกซึ่งจะเป็นข้อมูลบ่งบอกช่วงเวลาทำงานของกะนั้นๆว่าจากช่วงเวลาไหนถึงช่วงเวลาไหนเช่น D = 08:00-17:00 และสามารถเพิ่มได้ในอนาคต
5.มีระบบอับโหลดโอทีพนักงานที่ได้รับการอนุมัติแล้วผ่านไฟล์ Excel เข้าไปยังวันทำงานในแต่ละเดือน หากวันไดมีการทำโอทีหลายช่วงเวลาให้รวมเวลาของวันนั้นเข้าด้วยกันและหากมีการอับโหลดโอทีเดือนก่อนหน้าซึ่งล่าช้าเข้ามาในระบบจะต้องให้ Admin ตรวจสอบวันที่จะลงบันทึก OT ก่อน
6.มีระบบ Import ข้อมูลการลงเวลาทำงานจากเครื่องบันทึกเวลาเข้าออกพนักงาน โดยเชื่อมโยงกันด้วยหมายเลข GID และหรือ Employee No.เพื่อเปรียบเทียบการเข้างานของพนักงานงานว่าอยู่ในช่วงเวลาตาม Shift Code หรือไม่และคำนวน Late ของแต่ละวันหากมีการบันทึกซ้ำในเวลาใกล้เคียงกันจะใช้เวลาล่าสุด
7.มีระบบ Import รายได้อื่นๆของพนักงานในแต่ละเดือนเข้าไปเช่นค่า Team  Emergency หรือค่า Shift Allowance โดยเชื่อมโยงกันด้วยหมายเลข GID และหรือ Employee No.
8.มีระบบตรวจสอบและแก้ไข Time Sheet ของพนักงานดูข้อมูลการลงเลาเข้าออกเทียบกับ Shift Code แต่ละคนในแต่ละเดือนก่อนสรุปสามารถแก้ไขแบบ Manual สามารถแก้ไขตัวเลข OT 1.5 หรือ 3 เท่าและข้อมูลอื่นๆแบบรายวัน
9.มีระบบ Export Time Sheet เป็น PDF โดยสามารถ Export ทั้งหมด หรือเลือกรายแผนก รายเดือน หรือรายคนได้กรณีมีการแก้ใขใหม่และต้องการข้อมูลล่าสุด
10.มีระบบ Export CSV ข้อมูลส่ง Pay Roll เป็นไฟล์ CSV ซึ่งรายละเอียดส่วนนี้สร้างขึ้นเบื้องต้นก่อนและจัปรับปรุงรายละเอียดภายหลังซึ่งจะประกอบไปด้วย OT 1.5 หรือ 3 เท่าและค่า Team  Emergency หรือค่า Shift Allowance ที่เป็นเฉพาะรายได้เสริมของพนักงาน

***การออกแบบหน้า web Application***
1.หน้าแรกสำคัญมากจะแสดงตารางการทำงานของพนักงานในเดือนปัจจุบันโดยระดับ User สามรถแก้ไขได้เฉพาะพนักงานแผนกในสังกัดเท่านั้นส่วนแผนกอื่นๆจะเป็นรูปแบบการ View มี Filter เดือน-ปี และแผนกเพื่อใช้ดู
2.หน้า Import Shift Plan สามารถ Download Template เปล่าของแต่ละแผนกเพื่อใช้ในการจัดตารางการทำงานโดยเบื้องต้นจะมีรายชื่อพนักงานพร้อม GID ระบุเบื้องต้น เพื่อให้ วันเดือนปีตรงตามมาตรฐาน ก่อนทำการอับโหลดจะต้องเลือกเดือนปีและแผนกให้ถุกต้องก่อนการอับโหลดเพราะข้อมูลจะย้อนกลับไม่ได้
3.หน้า Import Shift Code สามารถดำเนินการอับโหลด แก้ไข เพิ่มเติมได้ด้วย Admin หากมีการลง Shift Code ที่ไม่มีในระบบมาจะมีการแจ้งเตือนในขั้นตอนการอับโหลด Shift Plan
4.หน้า Import OT ดำเนินการโดย Admin ข้อมูล OT ที่ Approved จะถูก export จากรายงานบน Power BI ในแต่ละเดือนเพื่อ Import เข้าไปยัง Time Sheet ของพนักงานแต่ละคนโดยเชื่อมโยงกันด้วยหมายเลข GID และหรือ Employee No. โดยแสดงข้อมูลบน Time Sheet มีตัวอย่างตามไฟล์แนบ
5.หน้า Import ข้อมูลการลงเวลาทำงานจากเครื่องบันทึกเวลาเข้าออกพนักงาน ดำเนินการโดย Admin เช่นเดียวกันข้อมูลนี้จะถูกอับโหลดหลายครั้งภายในเดือนนั้นๆให้ใช้ค่าล่าสุด โดยเชื่อมโยงกันด้วยหมายเลข GID และหรือ Employee No.
6.หน้าแสดงข้อมูล Time Sheet ของพนักงานเทียบ Shift code กับเวลาเข้าออกจากการอับโหลดจากเครื่องบันทึกเวลาเข้าออกพนักงานแสดงผลเหมือน Time Sheet ในตัวอย่างไฟล์แนบแต่ยังสามารถแก้ไขรายละเอีบดแบบ Manual ได้ด้วย Admin ส่วน User จะสามารถ View ได้เฉพาะแผนกตันสังกัดอยู่เท่านั้น
7.หน้า Export Time Sheet ส่วนนี้จะเป็นการ Export ข้อมูล Time Sheet ของพนักงานโดยสามารถเลือกได้ว่าจะ Export เดือน-ปีทั้งหมด รายแผนก หรือรายบุคคล
8.หน้า Export CSV ข้อมูลส่ง Pay Roll เป็นไฟล์ CSV จะสามารถเข้าถึงได้เฉพาะ Admin เลือกว่าต้องการ Export ข้อมูลเดือน-ปี ไหนก่อนการ Download ข้อมูลนี้ส่งการเงินต่อไป
9.มีหน้าจัดการ User หากมีการ Register โดย User แรกจะเป็น Admin อัตโนมัติและไม่ต้อง Activate แต่หากมีการขอเพื่อใช้งานระบบ Admin จะต้อง Activate User ก่อนเท่านั้นถึงจะใช้งานได้โดยข้อมูลแผนกจะต้องตรงกับฐานข้อมูลเพื่อจำกัดสิทธิ์
10.หน้าตั้งค่าข้อมูลอื่นๆที่จำเป็นและเป็นCenter สำหรับการ Download Template ที่จำเปป็นต้องใช้งานผ่านโปรแกรม
